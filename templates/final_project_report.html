Introduction:

For my project I set out to accomplish honing the skills needed to become a back-end developer. This included learning more about C++ and how it interacts with a computer, brushing up on Data Structures, Algorithms, and Leetcode for internship interviews, transition into learning and utilizing a common back-end language like C#, and attempting to work on a project that would be able to showcase these skills in a software application. Later in the semester I also found myself devoting significant time for filling out applications and networking events to test the waters of what it took to land a back-end internship. Looking back I feel the goals I set out to accomplish in August set me on the right path to not only become a more foundationally sound developer but also a more marketable applicant for back-end roles.

Background:

The main reason I set out to achieve these goals was because I wanted to be able to make myself a more marketable individual for a back-end positions. At the company I work for, Fidelity Investments, I communicate with multiple teams of back-end developers who, to keep it simple, work to automate manual operations and improve company processes' speed and efficiency while also adding new offerings to clients. On a weekly basis I get to see the level of problem solving, debugging, testing, and, most importantly, the amount of planning these back-end developers take part in.

At a high level the idea of building software that handles the mechanics of an application, but that a user can’t see (not a User Interface) is something I find very intriguing and exciting. Overall, I felt like the goals I set out to accomplish in my project would bring me closer to a backend role at my current company or another. Only time will tell but I do feel confident that I’m heading in the right direction.

Methodology, Materials and Methods:

I felt to truly understand debugging and problem solving seen in really any programming role, I needed to tackle a lower-level language like C++ and practice it consistently through programming shorter but complex Leetcode and DSA questions. Initially I set out to complete 75 –125 questions a month but learned quickly that was unrealistic to accomplish. Within the first few weeks I realized that 3-4 questions a week was more realistic to achieve and even that was challenging. When it came to relearning Data Structures and Algorithms my main resource was Neetcode.io and for practicing Leetcode questions I used Leetcode.com as well as Neetcode.io.

Another objective of mine was researching how the innerworkings of C++, its features, and how it interacts with a computer. I figured this would allow me to know what bugs I was facing was and likely where they were coming from when I created C++ programs and eventually programs in other languages. My main resources for learning C++ was YouTube and Bjarne Stroustrup “A Tour of C++” which I planned on writing a book report over my most notable learnings.

To tackle the planning and the testing aspect seen in back-end development I had hoped to be able to work on a project of my own that utilized the C++ features I learned and practiced in my Leetcode pursuits. My hopes where to have a small project (a C++ scientific calculator) or a visible contribution to my extracurricular Pan Out group’s Blockchain file transfer application. It would be nice to have either of these to showcase to potential hiring managers that I was able to plan, build, and test applications on my own.

Early in the semester I set out to practice coding interviews by attending networking events, applying to internship postings online, and hopefully getting some interviews call backs. I felt this would allow me to not only see the difficulty of Leetcode questions that were being asked but to also see if I was making any progress in answering them with all the Leetcode practice I was doing. This however took quite a bit of time in my early weeks as at some points I was traveling 40 minutes to campus and back just for a 1-hour networking events let alone some internship applications themselves took an hour to complete.

Results and Reflection:

Overall, my results were stronger in some areas than they were for others. For one I fell way short of my initial goal of completing 75-125 Leetcode questions a month. I completed around 2 questions a week if you count DSA questions as well. I pretty much accomplished 31 total questions this semester. While I do wish I completed more, I think is 2 is a fair number considering the amount of time I spent relearning Data Structures and Algorithms as I was completing these questions. The fact I was also solving these problems with newer programming language I was learning (C++) also didn’t speed things up early on. Currently the Neetcode.io course I’m working on for Data Structures and Algorithms has 17 lessons complete and there are 17 more to go. I would like to complete these other 17 lesson before the start of next semester. I’ve attached the repo link with most of my solutions to the Leetcode and Neetcodo.io DSA questions I’ve solved. Nonetheless I can’t begin to explain how much more quickly and confidently I’ve been completing C++ Leetcode questions since I’ve started. I do feel like I should be able to solve most easy to medium questions in interviews come next semester. I need to keep practicing and learning.

I did finish reading all 181 pages of Bjarne Stroustrup’s “A Tour of C++” and wrote a summary of the most interesting things I learned. The book covered the purpose of many C++ features like virtual functions, class hierarchies, iterator types, function adaptors, etc. If I’m being honest I do feel some of the topics covered I will likely never need to use but it was still interesting to learn about. There were also some topics that went a little over my head like Variadic Templates that I may need to go back over. Overall, I felt while the book had covered many interesting topics well, I do feel I should’ve gone the youtube course route as it would’ve been a more interactive and engaging approach to learning about a computer language rather than sitting and reading. While reading this book I did find myself watching a C++ course by a youtuber named Cherno that went over most of the topics covered in the book but was especially useful for topics that I didn’t understand. I will likely continue using this youtuber’s course as there are about 100 more lessons that will likely go further and further in depth over useful features of C++ and how its features interact with your machine and make your program.

The area I fell the shortest in was building and/or contributing to a project. Early on I felt that I overextended myself working on learning C++, DSA, Leetcode, and putting myself through the internship networking and interview cycle. At that point I knew that I wouldn’t be able to fit in a building a personal project as I just wasn’t going to have enough time to allocate to that pursuit. I did try to pursue at least contributing to a project, a Blockchain file transfer application, through my extracurricular “Pan Out” group. However, we didn’t get past the planning and work delegation stages of the project until later in the semester when I was already busy with my other pursuits and my job. I’m still in the group and they, like myself, have been struggling to consistently meet as of late but do hope to meet after the semester finishes. The one thing I can say I learned from falling short of having an application or contribution to show for is that I now know what I’m realistically capable of doing given the time I have. Looking back 5 hours a week was barely enough time to complete a lesson in the Neetcode.io course I was in along with finishing 2 Leetcode questions.

When it came to applying for internships, I ended up filling out 64 applications, attended 4 networking events, and received 3 interviews. Overall, I would’ve loved the response rate on my applications to be much higher but in this market I can’t complain too much. From the 3 companies I interviewed with 2 of them likely gave me the interview in the first place because I attended their networking events.

In those 3 internships interviews I found the Leetcode questions not to be as difficult as I expected. One of the questions named “2 sum” I had already learned and practiced multiple times already which reiterated the work I was doing was paying off. For the most part though the interviews went smoothly but I realized there were a more questions about experience and projects in all 3 of them than I expected. Experience I can talk about plenty about with my current BPMN developer role at Fidelity but my project portfolio was lacking and there were times I could tell talking about a single real project that I completed through a course seemed to be a little bit of a letdown for the interviewer. Nonetheless I learned what I need to about networking, how the interviewing is conducted, and applying to these mostly back-end internships. I know now that I have a lot of work to do on the project portfolio front but questions about Leetcode and DSA I have solid footing on. My plan is to hopefully transition into a back-end language like C# sometime in January and start a small project of my own going into next semester.

Conclusion:

Overall, I’m pleased with what I accomplished in this course for the semester. If I could put all my achievements into one word it would be “foundational”. My foundation in C++ and how computer languages interact with memory and compile to direct the operating system is much stronger than it was before. My foundational understanding of common Data Structures and Algorithms is second nature at this point. My foundational knowledge for networking, interview, and applying for back-end roles is now more built up significantly. I know that I just need to keep adding to these foundational skills going forward but also begin to apply them, specifically my knowledge of C++ and programming languages, into projects where I can show my understanding of programming as well as my creativity. I do feel once I start contributing and building projects on my own time, my chances of getting an internship next semester or a job by next fall will go up significantly. I can’t wait to take on this next chapter.
